# MapLink Jamaica Website

Official static website for **MapLink JA**.

## Files

- `index.html` — homepage
- `css/style.css` — site design and responsive styling
- `js/main.js` — mobile navigation, animations, and visibility checker
- `images/maplink-ja-logo.png` — supplied business logo

## Before launch

Update these placeholders in `index.html`:

1. WhatsApp link: replace `https://wa.me/` with the full WhatsApp click-to-chat URL.
2. Confirm the business email address.
3. Replace introductory testimonial statements with verified customer testimonials.
4. Add the Jotform survey link after the form is completed.
5. Add privacy and terms pages before collecting sensitive client information.

## Deployment

Upload all files and folders to the root of the GitHub repository. Cloudflare Pages will redeploy automatically.
